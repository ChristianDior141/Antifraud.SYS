# Records of Processing Activities (RoPA)

**Регламент:** GDPR Статья 30 • **Система:** Antifraud.SYS • **Версия:** 1.0 • **Дата:** 2026-06-04

> Реестр операций обработки персональных данных. Поддерживается вместе с кодом
> и обновляется при изменении модели данных или бизнес-процессов.

## Роли

| Роль | Описание |
|---|---|
| Контролёр (Controller) | Финансовая организация, эксплуатирующая Antifraud.SYS |
| Обработчик (Processor) | Хостинг/облачный провайдер, провайдер e-mail (опц.) |
| DPO | Ответственный за защиту данных (предлагаемая роль, Stage 4 — отложена) |

---

## 1. KYC / онбординг клиентов

| Поле | Значение |
|---|---|
| **Цель обработки** | Идентификация клиента, проверка благонадёжности, выполнение требований AML/KYC |
| **Правовое основание** | Юридическая обязанность (AML-законодательство); согласие (Art.6(1)(c), 6(1)(a)) |
| **Категории субъектов** | Клиенты (физлица) |
| **Категории данных** | ФИО, дата рождения, гражданство, адрес, телефон, e-mail, номер документа, занятость, доход, источник средств, PEP-статус |
| **Особые категории** | PEP-статус (повышенный риск) |
| **Получатели** | Внутренние: комплаенс, аналитики, админ. Внешние: регулятор (по запросу), санкционные провайдеры |
| **Хранение** | 5 лет после завершения отношений (AML), затем анонимизация (`retention_until`) |
| **Меры защиты** | Шифрование PII at-rest (Fernet), RBAC, аудит доступа, TLS |
| **Где в системе** | `client_profiles`, `kyc_forms`, `documents` |

## 2. AML-мониторинг операций

| Поле | Значение |
|---|---|
| **Цель** | Выявление подозрительных операций, формирование алертов и кейсов |
| **Правовое основание** | Юридическая обязанность (AML) |
| **Категории субъектов** | Клиенты, контрагенты |
| **Категории данных** | Суммы, валюта, контрагенты, страны, IP, device_id, история операций |
| **Получатели** | Комплаенс, аналитики; регулятор (SAR) |
| **Хранение** | 5 лет (AML) |
| **Меры защиты** | RBAC, аудит, неизменяемый журнал (hash-chain) |
| **Где в системе** | `transactions`, `aml_alerts`, `incident_tickets` |

## 3. Оценка риска и скоринг

| Поле | Значение |
|---|---|
| **Цель** | Расчёт риск-профиля клиента |
| **Правовое основание** | Юридическая обязанность; законный интерес |
| **Категории данных** | Производные риск-факторы, поведенческие метрики |
| **Автоматизированное решение** | Скоринг — вспомогательный; финальное решение принимает человек (нет полностью автоматического решения по Art.22) |
| **Хранение** | Срок жизни связанного профиля |
| **Где в системе** | `risk_scores` |

## 4. Управление доступом и аутентификация

| Поле | Значение |
|---|---|
| **Цель** | Аутентификация, авторизация, защита учётных записей |
| **Правовое основание** | Законный интерес (безопасность) |
| **Категории субъектов** | Сотрудники, клиенты |
| **Категории данных** | E-mail, хеш пароля, MFA-секрет (шифр.), журнал входов, IP, user-agent |
| **Хранение** | Срок жизни аккаунта; журналы — по политике хранения логов |
| **Меры защиты** | bcrypt, шифрование MFA-секрета, lockout, MFA, отзыв токенов |
| **Где в системе** | `users`, `audit_logs`, `revoked_tokens`, `password_reset_tokens` |

## 5. Аудит и подотчётность

| Поле | Значение |
|---|---|
| **Цель** | Контроль действий, расследования, соответствие |
| **Правовое основание** | Юридическая обязанность; законный интерес |
| **Категории данных** | user_id, действие, ресурс, IP, user-agent, метки времени, hash-chain |
| **Хранение** | Не менее срока AML-ретеншена |
| **Меры защиты** | Неизменяемость (hash-chain), RBAC (только админ/аудитор) |
| **Где в системе** | `audit_logs` |

## 6. Управление согласиями

| Поле | Значение |
|---|---|
| **Цель** | Учёт и отзыв согласий субъектов |
| **Правовое основание** | Согласие (Art.7) |
| **Категории данных** | Цель, версия политики, статус, время, IP |
| **Где в системе** | `consents` |

## 7. Запросы субъектов данных (DSAR)

| Поле | Значение |
|---|---|
| **Цель** | Реализация прав субъектов (Art.15–20) |
| **Правовое основание** | Юридическая обязанность |
| **SLA** | 30 дней (`due_at`) |
| **Где в системе** | `data_subject_requests` |

## Сводка прав субъекта и их реализации

| Право (GDPR) | Реализация в Antifraud.SYS |
|---|---|
| Доступ (Art.15) | `GET /privacy/my-data/export` |
| Переносимость (Art.20) | экспорт в JSON |
| Исправление (Art.16) | `PUT /clients/profile/me`, DSAR `rectification` |
| Удаление (Art.17) | DSAR `erasure` → анонимизация (с учётом AML legal hold) |
| Ограничение (Art.18) | DSAR `restriction` → `processing_restricted` |
| Отзыв согласия (Art.7) | `POST /privacy/consents` (granted=false) |
| Возражение (Art.21) | через DSAR / обращение к DPO |
